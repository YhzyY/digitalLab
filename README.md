# 数字孪生城市虚拟仿真实验

在 Chrome 或 Edge 打开 [index.html](index.html) 即可进入实验首页。页面使用原生 HTML、CSS、JavaScript 和随项目提供的 Three.js r186。运行时可离线使用。

## 实验

- **数字孪生城市搭建（第 1–11 步）**。在与教学街区配准的仿真航拍底图上选定测区，导入资料、校核坐标、布点和航拍，练习影像匹配、成果生成、精度核验和对象建档。
- **多源数据融合（第 12–17 步）**。定位三台设备，绑定道路和河段，调阅设备样本，核对视频过线、重复批次和融合来源。
- **智能态势感知（第 18–21 步）**。把观测映射到对象，回放车流、河面上涨和漫岸，核对提示阈值、现场水深和设备台账。

场景包含中央湖泊公园、河道、两岸街区和跨河桥梁。街区使用 Three.js 实时绘制，可拖动旋转、滚轮缩放。观测窗口采用教学样本；交通与漫岸动画用于解释观测。切换方案可先预览场景，完成工作台操作后应用结果。

查看已完成的早期步骤可以回看当时的城市状态。应用更改后的前序配置时，会提示重新执行受影响的后续步骤。模块、步骤、草稿及已应用配置保存在本机浏览器。首页可在确认后从空场景重做。

## 本地原型与正式接入

街区、观测和视频轨迹均为虚拟教学样例。直接打开 HTML 时使用浏览器本机进度。测试实验空间接口时，用 Node.js 20 或更新版本在项目目录启动本地服务，无需安装依赖：

```sh
node local-server.cjs
```

首页为 `http://127.0.0.1:4173/`。进入 [实验空间测试对接页面](https://shenbao.ilab-x.com/declare/wiki/v2#2-1)，按页面说明登录公开测试账号，从公测课程页点击「我要做实验」，将跳转地址填写为 `http://127.0.0.1:4173/entry`。在运行本地服务的电脑浏览器打开实验空间产生的带 `ticket` 链接，网页会自动识别学生并恢复本地服务记录。

完成第 21 步后，可提交成绩、查询回传结果，以及在成绩成功后上传 PDF 报告。成绩默认用于联调，前 16 步各 5 分、后 5 步各 4 分，共 100 分，合理用时暂设 60 秒。规则判定与合成轨迹按零次 AI 调用回传。报告最多 5 MB，当前页面仍提供 JSON 导出。

本地服务默认使用官方公开测试配置。自定义对接时同时设置 `ILAB_API_BASE`、`ILAB_APPID`、`ILAB_SECRET`，按需设置 `ILAB_TITLE`。可用 `PORT` 更换监听端口，用 `ILAB_STATE_FILE` 指定状态文件。macOS 默认将进度和接口凭证持久化到 `~/Library/Application Support/digital-city-ilab/state.json`。运行 `node --test scripts/ilab.test.cjs` 可验证签名、请求参数和提交结构。

街区由 city-simulation.js 生成，city-view.js 负责渲染、相机和设备取景。Three.js 的许可见 [MIT 许可](assets/vendor/THREE-LICENSE.txt)。
