# 孪生城市虚拟仿真实验

直接在 Chrome 或 Edge 打开 [index.html](index.html)，点击「打开演示」。页面使用原生 HTML、CSS、JavaScript 和随项目提供的 Three.js r186。运行时可离线使用。

## 实验

- **数字孪生城市搭建环节**。从空场景设置范围，加入道路、彩色建筑、地面与绿化，再校核坐标、关联设备和映射观测。
- **多源数据融合环节**。操作样例记录和视频轨迹，练习字段映射、清洗、过线计数、窗口对齐、融合、对照和新增设备接入。
- **智能态势感知数据处理环节**。配置建筑火警、道路拥堵和积水规则，模拟缺测，追查证据，回看扰动前后并导出记录。

训练页使用 Three.js 透视相机，可拖动旋转、滚轮缩放、切换全景和街道视角。应用步骤时，路网逐步展开、建筑升起、校核点和设备加入场景。第 7 步生成沿车道行驶的车辆，时间窗口和融合策略改变车流密度，拥堵和积水改变车速。数据关联显示为沿设备到道路传输的三维标记。积水以可升降的波动水面显示，建筑火警候选以动态烟雾表示。可暂停和继续仿真。

查看已完成的早期步骤可以回看当时的城市状态。应用更改后的前序配置时，会提示重新执行受影响的后续步骤。模块、步骤、草稿及已应用配置保存在本机浏览器。首页可在确认后从空场景重做。

## 本地原型与正式接入

街区、观测和视频轨迹均为虚拟教学样例。带 `?token=标识` 的链接可以在同一浏览器区分本地进度。该静态入口用于演示，正式的 Token 验证和远程进度需联调。

场景由 [scripts/build-scene.py](scripts/build-scene.py) 生成。只有重新制作街区时才需要 Python 和 Pillow。[建筑立面贴图](assets/facade-atlas.webp)由内置图像生成工具制作，生成提示为四种正立面纹理的 2×2 图集，包括浅色石材住宅、蓝灰办公玻璃、暖砖住宅和灰色混凝土办公楼。采用正视、均匀自然光和可重复贴图构图。Three.js 的发布版本及许可见 [r186](https://github.com/mrdoob/three.js/releases/tag/r186) 和 [MIT 许可](assets/vendor/THREE-LICENSE.txt)。
